## 2. 引入模板文件，传入占位符参数

```html

<!-- 模板文件的引用-->
{% extends "layout.html" %}

<!--占位符传参-->
{% block content %}

    <div class="container">
        <div style="margin-bottom: 20px;margin-top: 30px;" >
            <a class="btn btn-success" href="/depart/add/">
                <i class="bi bi-database-add"></i>
                新建部门
            </a>
        </div>

        <div class="card border-primary mb-3" style="margin-bottom: 10px;">
            <div class="card-header">
                 <i class="bi bi-android"></i>
                部门列表

            </div>
            <div class="card-body text-primary">

                <div class="bd-example">
                    <table class="table table-dark table-hover">
                        <thead>
                        <tr>
                            <th scope="col">ID</th>
                            <th scope="col">名称</th>
                            <th scope="col">操作</th>
                        </tr>
                        </thead>
                        <tbody>
                        {% for obj in queryset %}
                        <tr>
                        {% csrf_token %}
                            <th scope="row">{{ obj.id }}</th>
                            <td>{{ obj.title }}</td>
                            <td>
                                <a class="btn btn-primary btn-sm" href="/depart/{{ obj.id }}/edit/">编 辑</a>
                                <a class="btn btn-danger btn-sm" href="/depart/delete/?nid={{ obj.id }}">删 除</a>
                            </td>
                        </tr>
                        {% endfor %}
                        </tbody>

                    </table>
                </div>

            </div>
        </div>

    </div>

{% endblock %}
```

```text

1. 模板文件定义：

 定义方法：
 
 在需要使用的某个文件作为模板的时候， 在指定区域 放入占位符:
             
            {% block content %}
            
            
            {% endblock %}
            
2. 加载模板文件，并给占位符传入参数

加载方法/导入模板头文件：

{% extends "模板文件名" %}
```
占位符传参法：
{% block content %}

   html代码内容

{% endblock %}

    {% block content2 %}


    {% endblock %}
