# 需要对应数据库参数方法


## 1. 性别/等级/等 对照字段回显方法
```python

from django.db import models

# 数据库定义如下：
# 为了节省空间，例如姓名，等级，级别 等通常会使用数字对照定义法，在数据库
# 在数据库中显示的为数字，需对照显示实际参数时
#Django内置了get_字段名_display()进行自动对照

# 如下的sex性别就可以用get_sex_display()显示原数据

gender_choice = (
    (1, "男"),
    (0, "女"),
)
sex = models.SmallIntegerField(verbose_name="性别", choices=gender_choice)
# 用1，2小整型表示性别，choices去对照性别

# 取值的对应的时候，Django提供一个函数
# get_字段名称_display() 
#          ||
#     get_sex_display() 


```
