## bootstrap_datepicker使用方法

### 1. 引入css
    <link rel="stylesheet" href="{% static 'plugins/bootstrap-datetimepicker/css/bootstrap-datetimepicker.min.css' %}">

### 2. 引入js
    <link rel="stylesheet" href="{% static 'plugins/bootstrap-datetimepicker/js/bootstrap-datetimepicker.min.js' %}">
    <link rel="stylesheet" href="{% static 'plugins/bootstrap-datetimepicker/js/locales/bootstrap-datetimepicker.zh-CN.js' %}">

### 3.js调用


```调用方法

1. 

<input id="dt" type="text" name="time" class="form-control" placeholder="入职时间"> 定义id="dt"
 
 
2. js代码：    

<script>
     $(function(){
         $('#dt').datepicker({
             format:'yyyy-mm-dd',
             startDate:'0',
             language:"zh-CN",
             autoclose:true
         });
    })
</script>
```

### 4. Modelform调用的input框使用方法

<input type="text" name="create_time" class="form-control" required="" id="id_create_time">

浏览器后台如上

即：modelfrom组件的input框默认的id为= id_字段名

即：
2. js调用代码如下：    

<script>
     $(function(){
         $('#id_字段名').datetimepicker({
             format:'yyyy-mm-dd',
             startDate:'0',
             language:"zh-CN",
             autoclose:true
         });
    })
</script>
```
