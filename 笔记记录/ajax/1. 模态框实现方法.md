# 模态框

## 1. 通过JQuery实现

<!-- 绑定模态框的按钮 -->
* 给任意按钮加上下列按钮方法，绑定到模态框，即可实现点击按钮，弹出对话框
> data-bs-toggle="modal" data-bs-target="#exampleModal"

<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="*****绑定模态框id*****">
  Launch demo modal
</button>

<!-- 模态框 -->
<div class="modal fade" id="*******被绑定id*******" tabindex="-1" aria-labelledby="exampleModalLabel" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title" id="exampleModalLabel">Modal title</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Close"></button>
      </div>
      <div class="modal-body">
        ...
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Close</button>
        <button type="button" class="btn btn-primary">Save changes</button>
      </div>
    </div>
  </div>
</div>

## 2.通过JS实现

```js

    // 按钮：
<input id="btnAdd" type="button" value="新建订单" class="btn btn-primary">

    // -- 模态框----新建订单（对话框）-->
<div class="modal fade" id="myModal" tabindex="-1" aria-labelledby="exampleModalLabel" aria-hidden="true">
    <div class="modal-dialog">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title" id="exampleModalLabel">Modal title</h5>
                <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Close"></button>
            </div>
            <div class="modal-body">
                ...
            </div>
            <div class="modal-footer">
                <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Close</button>
                <button type="button" class="btn btn-primary">Save changes</button>
            </div>
        </div>
    </div>
</div>

     JS：
    <script type="text/javascript">
        
         $(function() {
             bindBtnAddEvent();
         })
                
         function bindBtnAddEvent() {
               // 按钮id： btnAdd---记得替换
             $("#btnAdd").click(function(){
                 // 模态框id：myModal --点击按钮，显示对话框
                 $("#myModal").modal('show');
             })
         }
         
    </script>
     

```
